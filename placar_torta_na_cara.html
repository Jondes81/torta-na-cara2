Como Conectar o BBC micro:bit

Para usar esta interface com os botões físicos, grave o código Python abaixo no seu BBC micro:bit no editor MakeCode. 

# CÓDIGO MAKECODE PYTHON (TORTA NA CARA PRO)
bluetooth.start_uart_service()
strip = neopixel.create(DigitalPin.P16, 24, NeoPixelMode.RGB)

pins.set_pull(DigitalPin.P0, PinPullMode.PULL_DOWN)
pins.set_pull(DigitalPin.P1, PinPullMode.PULL_DOWN)
pins.set_pull(DigitalPin.P2, PinPullMode.PULL_UP)

TRAVA = 0
ultimo_A = 0
ultimo_B = 0

def on_forever():
    global TRAVA, ultimo_A, ultimo_B
    t = input.running_time()
    
    A = pins.digital_read_pin(DigitalPin.P0)
    B = pins.digital_read_pin(DigitalPin.P1)
    C = pins.digital_read_pin(DigitalPin.P2)
    
    # RESET PELO JUIZ (BOTÃO C / P2)
    if C == 0:
        TRAVA = 1
        bluetooth.uart_write_string("RESET\n")
        basic.show_icon(IconNames.YES)
        strip.show_color(neopixel.colors(NeoPixelColors.WHITE))
    
    # BATEU JOGADOR A (P0)
    if A == 1 and TRAVA == 1:
        if t - ultimo_A > 150:
            TRAVA = 0
            ultimo_A = t
            bluetooth.uart_write_string("PONTO_A\n")
            basic.show_string("A")
            strip.show_color(neopixel.colors(NeoPixelColors.GREEN))
            
    # BATEU JOGADOR B (P1)
    if B == 1 and TRAVA == 1:
        if t - ultimo_B > 150:
            TRAVA = 0
            ultimo_B = t
            bluetooth.uart_write_string("PONTO_B\n")
            basic.show_string("B")
            strip.show_color(neopixel.colors(NeoPixelColors.YELLOW))
            
    basic.pause(10)

basic.forever(on_forever)

Passo a Passo de Emparelhamento:

  1. Ligue o micro:bit e certifique-se que o Bluetooth está ativo.
  2. Clique no botão azul "Conectar Bluetooth" no topo desta página.
  3. Selecione o BBC micro:bit na janela do navegador.
  4. Pronto! O status ficará verde e as batidas aparecerão instantaneamente na TV.
Atalhos de Teclado (Juiz):
Espaço: Reset/Liberar Rodada | Tecla A: Vitória A | Tecla B: Vitória B | F11: Tela Cheia.
